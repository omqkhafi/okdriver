# 035. No client-side parameter interpolation by default

## Status
Accepted

Roadmap status: New; Open (FS-18)

## Open question
Whether an opt-in is ever allowed is not settled; FS-18 decides it.

## Decision
No client-side parameter interpolation by default; a capability error instead; opt-in only if FS-18 proves it safe

## Basis
Security review
