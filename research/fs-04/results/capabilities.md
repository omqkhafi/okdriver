# Capability table

Generated by `scripts/capabilities.ts` from `rules.json` and the files in `results/probes/`. Do not edit by hand.

**Rule.** A capability is true only when every required cell passed in 5 of 5 fresh runs, end to end, with server-side truth (pg_stat_ssl and server log, PostgreSQL SHA-256, pg_stat_activity, SQLSTATE, server processlist). A cell is a variant (all its required checks) or one named check of a variant. 1 to 4 of 5 in any cell, and no cell at 0 of 5, is "intermittent": false, counts shown. Any cell at 0 of 5 is false. Documented-only and unobservable are false. A negated cell counts the runs in which the named check failed. The production column is true only from results/production/ files made against a deployed Worker; otherwise it reads "Not verified here" and the claimable value is false.

**Labels.** `local-observed`: measured on the pinned workerd with embedder trust settings, not Cloudflare production. `documented-only`: stated by a page, not measured. `not observable`: no API or instrument; false. The claimable value is the production column; no production run exists, so every claimable value is false.
